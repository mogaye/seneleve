# Textes des 4 écrans du site — avec emplacements

Ces textes concernent uniquement les quatre écrans des maquettes fournies. Chaque écran a son propre objectif, son propre titre et ses propres boutons : **cours**, **exercices et examens**, **outils de révision**, **préparation aux examens**.

---

## Écran 1 — Cours (maquette bleue)

**Objectif de l’écran :** aider l’élève à choisir une matière, suivre les leçons et comprendre le cours.

| Emplacement dans la maquette | Texte à placer |
|---|---|
| Barre latérale tout à gauche — icône de la page | **Cours** |
| Petit badge en haut à gauche du grand panneau | **COURS** |
| En-tête du grand panneau central | **Apprends chaque leçon pas à pas** |
| Sous le titre, dans le grand panneau central | *Choisis une classe et une matière pour découvrir le programme, les explications et les exemples.* |
| Zone de recherche du panneau principal | **Rechercher une leçon…** |
| Bouton à côté de la recherche | **Rechercher** |
| Pastilles en haut à droite du panneau principal | **Étape 1 · 2 · 3 · 4** — indiquer la progression dans la sélection classe → matière → leçon → cours |
| Petite zone en bas à gauche du panneau principal | **Reprendre mon cours** |
| Texte sous ce bouton | *Continue là où tu t’étais arrêté.* |
| Panneau vertical à droite — titre | **Choisir une matière** |
| Lignes de choix dans le panneau droit | **Français** · **Mathématiques** · **Sciences** · **Histoire-Géographie** · **Autres matières** |
| Ligne sélectionnée dans le panneau droit | Afficher le nom de la matière active, par exemple **Mathématiques** |
| Bouton en bas du panneau droit | **Voir les leçons** |
| Panneau inférieur gauche — titre | **Progression du cours** |
| Panneau inférieur gauche — texte | *[Nombre] leçons consultées sur [total].* |
| Barre de progression en bas du panneau inférieur gauche | Remplir selon les leçons consultées |
| Carte inférieure du milieu — titre | **Leçon suivante** |
| Carte inférieure du milieu — bouton principal bleu | **Continuer la leçon** |
| Panneau inférieur droit — titre | **À retenir** |
| Panneau inférieur droit — texte | *Les notions essentielles de cette leçon apparaîtront ici.* |
| Petit indicateur en bas de page | **Leçon [x] sur [total]** |

### Quand une leçon est ouverte

| Emplacement | Texte |
|---|---|
| En haut du contenu de leçon | **[Titre de la leçon]** |
| Sous le titre | **Objectif :** [ce que l’élève saura faire] |
| Dans la zone de cours | **La leçon** |
| Au-dessus des exemples | **Exemples expliqués** |
| Bouton de bas de page à gauche | **Leçon précédente** |
| Bouton de bas de page à droite | **Faire les exercices** |

## Écran 2 — Exercices & examens (maquette verte)

**Objectif de l’écran :** faire pratiquer l’élève et lui permettre de vérifier ses réponses. Il est centré sur l’entraînement, contrairement à l’écran Cours qui explique les notions.

| Emplacement dans la maquette | Texte à placer |
|---|---|
| Barre latérale tout à gauche — icône de la page | **Entraînement** |
| Petit badge au-dessus de l’activité principale | **EXERCICES & EXAMENS** |
| En-tête du panneau principal | **À toi de t’entraîner !** |
| Sous le titre, dans le panneau principal | *Résous les questions, puis consulte la correction pour comprendre tes erreurs.* |
| Panneau de gauche — titre | **Choisir un entraînement** |
| Lignes du panneau gauche | **Exercices par leçon** · **Devoirs** · **Sujets d’examen** · **Corrigés** |
| Filtres au-dessus ou à côté de la liste | **Classe** · **Matière** · **Leçon** |
| Filtre de difficulté | **Niveau** : Découverte · Entraînement · Défi |
| Zone de la question dans le panneau principal | **Question [numéro]** |
| Consigne de l’exercice | **[Énoncé de la question]** |
| Bouton sous les réponses | **Valider ma réponse** |
| Bouton secondaire | **Passer la question** |
| Panneau droit — titre | **Mon entraînement** |
| Panneau droit — indicateur | **Question [x] sur [total]** |
| Panneau droit — progression | Barre indiquant les questions déjà faites |
| Bouton vert principal en bas du panneau principal | **Terminer l’exercice** |
| Sous la barre de progression | *Tu pourras revoir tes réponses avant de terminer.* |

### Après validation d’une réponse

| Emplacement | Texte |
|---|---|
| Message si la réponse est correcte | **Bonne réponse !** |
| Explication sous le message | *Voici pourquoi cette réponse est juste : [explication].* |
| Message si la réponse est incorrecte | **Pas encore. Regarde la correction et réessaie.** |
| Bouton après la correction | **Question suivante** |

### Écran de résultat

| Emplacement | Texte |
|---|---|
| En haut du panneau principal | **Entraînement terminé** |
| Résultat au centre | **Ton résultat : [score] / [total]** |
| Commentaire dynamique | *Très bien !* / *Bon début, continue à t’entraîner.* |
| Bouton principal | **Revoir mes erreurs** |
| Bouton secondaire | **Recommencer** |
| Lien vers le cours lié | **Revoir la leçon** |

## Écran 3 — Quiz, Flashcards, Résumé, Planning (maquette orange)

**Objectif de l’écran :** proposer plusieurs façons de réviser une leçon. Cet écran est centré sur la mémorisation et l’organisation personnelle, pas sur un exercice noté.

| Emplacement dans la maquette | Texte à placer |
|---|---|
| Barre latérale tout à gauche — icône de la page | **Révisions** |
| Badge en haut à gauche du grand panneau | **RÉVISER** |
| Titre principal du grand panneau | **Révise à ta façon** |
| Texte sous le titre | *Choisis un outil pour retenir l’essentiel et revenir sur les notions difficiles.* |
| Onglets en haut à droite | **Quiz** · **Flashcards** · **Résumé** · **Planning** |
| Panneau inférieur gauche — titre | **Mes leçons** |
| Panneau inférieur gauche — lignes | Leçons enregistrées ou sélectionnées par l’élève |
| Panneau inférieur gauche — recherche | **Chercher une leçon…** |
| Carte centrale — titre | Nom de l’outil actif : **Quiz**, **Flashcards**, **Résumé** ou **Planning** |
| Carte inférieure centrale — bouton | Bouton qui change selon l’onglet actif |
| Panneau inférieur droit — titre | **Ma séance** |
| Panneau inférieur droit — texte | Afficher la durée, le nombre de cartes ou l’avancement de la séance |
| Barre du bas | Avancement dans la séance de révision |

### Contenu de l’onglet Quiz

| Emplacement | Texte |
|---|---|
| Carte centrale — titre | **Quiz de révision** |
| Carte centrale — consigne | *Réponds à quelques questions pour vérifier ce que tu as retenu.* |
| Bouton principal | **Lancer le quiz** |
| Après le quiz | **Voir les notions à revoir** |

### Contenu de l’onglet Flashcards

| Emplacement | Texte |
|---|---|
| Carte centrale — titre | **Cartes mémoire** |
| Carte centrale — consigne | *Lis la question, réfléchis, puis retourne la carte pour voir la réponse.* |
| Boutons sous la carte | **Je savais** · **À revoir** |
| Bouton principal | **Commencer les cartes** |

### Contenu de l’onglet Résumé

| Emplacement | Texte |
|---|---|
| Carte centrale — titre | **Résumé de la leçon** |
| Carte centrale — texte | *Retrouve les définitions, règles et idées principales en un coup d’œil.* |
| Bouton principal | **Lire le résumé** |
| Lien secondaire | **Ouvrir le cours complet** |

### Contenu de l’onglet Planning

| Emplacement | Texte |
|---|---|
| Carte centrale — titre | **Mon planning de révision** |
| Carte centrale — consigne | *Répartis tes leçons sur les jours disponibles.* |
| Champs dans la carte | **Matières** · **Jours disponibles** · **Temps par jour** |
| Bouton principal | **Créer mon planning** |
| Message après création | **Ton planning est prêt.** |
| Lien secondaire | **Modifier mes séances** |

## Écran 4 — Préparation aux examens (maquette rouge)

**Objectif de l’écran :** accompagner l’élève dans la préparation d’un examen précis avec une vue d’ensemble, des sujets et un plan de travail.

| Emplacement dans la maquette | Texte à placer |
|---|---|
| Barre latérale tout à gauche — icône de la page | **Examens** |
| Badge en haut à gauche de la grande zone de préparation | **PRÉPARATION EXAMEN** |
| En-tête de la page | **Prépare ton examen avec méthode** |
| Texte sous le titre | *Retrouve les matières à réviser, les sujets d’entraînement et ton plan de préparation.* |
| Carte supérieure gauche — intitulé | **Examen préparé** |
| Carte supérieure gauche — valeur | **CFEE**, **BFEM** ou **Baccalauréat** |
| Carte supérieure centrale — intitulé | **Date de l’examen** |
| Carte supérieure centrale — valeur | **[Date choisie]** ou **À renseigner** |
| Carte supérieure droite — intitulé | **Jours restants** |
| Carte supérieure droite — valeur | **[Nombre] jours** |
| Liste ou panneau à droite — titre | **Matières à réviser** |
| Lignes de la liste droite | Matières correspondant à l’examen ou à la série choisie |
| État de chaque matière | **À commencer** · **En cours** · **Révisée** |
| Grande zone principale — titre | **Mon plan de préparation** |
| Grande zone principale — contenu | Liste chronologique des révisions, exercices et examens blancs |
| Bouton rouge principal en bas de la zone principale | **Créer mon plan de révision** |
| Bouton secondaire | **Voir les sujets d’examen** |
| Barre ou indicateur inférieur | **Préparation : [pourcentage] %** |

### Quand l’examen choisi est le baccalauréat

| Emplacement | Texte |
|---|---|
| Sélecteur de série | **Choisir ma série** |
| Options | L1a/L1b · L’1 · L2 · S1 · S2 · S3 · S4 · S5 · STEG · STIDD · F6 · Franco-arabe |
| Texte d’aide sous le sélecteur | *Les matières affichées dépendent de la série sélectionnée.* |

### État de préparation

| Emplacement | Texte |
|---|---|
| Carte de conseils | **Conseil du jour** |
| Texte du conseil | *Commence par revoir une leçon, puis vérifie tes acquis avec un sujet ou un quiz.* |
| Message de progression | **Tu avances bien. Continue selon ton planning.** |
| État sans date | **Ajoute la date de ton examen pour organiser tes révisions.** |

---

## Différences à garder entre les 4 écrans

| Écran | L’élève vient pour… | Bouton principal |
|---|---|---|
| **Cours — bleu** | Comprendre une notion et suivre une leçon | **Continuer la leçon** |
| **Exercices & examens — vert** | Répondre à des questions et vérifier ses réponses | **Valider ma réponse** |
| **Révisions — orange** | Mémoriser, faire un quiz ou organiser ses séances | **Lancer l’outil choisi** |
| **Préparation aux examens — rouge** | Se préparer à une épreuve avec un plan et des sujets | **Créer mon plan de révision** |
